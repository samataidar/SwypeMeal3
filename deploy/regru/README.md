# Деплой на хостинг reg.ru («Хост-0»)

Архив `swypemeal-regru.zip` содержит собранный фронтенд и два служебных файла:

- `.htaccess` — SPA-фолбэк и маршрутизация `/api/*`, `/images/*` на `proxy.php`;
- `proxy.php` — прокси на Render и Unsplash через cURL (на shared-хостинге
  `mod_proxy` обычно отключён, поэтому PHP).

## 1. Подготовка в панели reg.ru

1. **Хостинг → сайт** → запомните корневую папку сайта (обычно `www/<домен>/`).
2. Включите **PHP 8.x** (Хост-0 поддерживает; нужен модуль `curl` — он есть по умолчанию).
3. Включите **HTTPS/Let's Encrypt** для домена (можно после привязки).

## 2. Загрузка

1. Откройте файловый менеджер (или подключитесь по FTP/SFTP).
2. Загрузите `swypemeal-regru.zip` в корневую папку сайта.
3. Распакуйте архив там же (файлы должны лежать рядом: `index.html`, `assets/`,
   `.htaccess`, `proxy.php`).

## 3. Проверка на временном домене

Откройте выданный хостингом адрес (вида `*.regruhosting.ru` или IP):

- `/` — приложение открывается;
- `/api/health` — `{"status":"healthy",...}`;
- `/api/diag` — страница диагностики;
- `/images/photo-...` — картинка (jpeg).

Если `/api/health` отдаёт `502` — проверьте, что PHP-модуль `curl` включён и
исходящие запросы не заблокированы (в логах хостинга будет `[proxy] upstream failed`).

## 4. Привязка поддомена

1. В панели хостинга добавьте домен/поддомен `app.swypemeal.ru` к сайту —
   панель покажет, какой A-запись должен указывать на её IP.
2. В reg.ru → DNS `swypemeal.ru`: замените CNAME `app` на **A** с этим IP.
3. Дождитесь обновления DNS (TTL 300–3600) и выпустите SSL-сертификат в панели.

## 5. Зачем это нужно

Такой стенд полностью российский: домен `.ru`, DNS reg.ru, хостинг reg.ru.
Если он открывается у проблемных пользователей, а `swypemeal.ru` (Vercel) — нет,
значит фильтр привязан к зарубежной инфраструктуре/имени и переезд решает задачу.
